# Job Portal

A full-stack Job Portal application built using React, Vite, JSON Server, Axios, and React Router.

## 🚀 Live Demo

**Frontend:**  
https://jobportal-w0sm.onrender.com

**Backend API:**  
https://jobportal-api-y1nt.onrender.com

## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript
- React Router
- Axios
- JSON Server
- HTML5
- CSS3
- Git & GitHub
- Render

## ✨ Features

- User Registration
- User Login
- Forgot Password
- Protected Routes
- Browse Jobs
- Search Jobs
- View Job Details
- Add Jobs
- Edit Jobs
- Delete Jobs
- Recruiter and Job Seeker roles
- REST API integration
